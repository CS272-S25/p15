# CS472 Group Project

This websitewas created as a group project for the course CS472: Intro to Web Development at the University of Wisconsin–Madison. The goal of the site is to provide an easy-to-use one-stop shop where students can find all materials relevant to their courses, such as lecture slides, video recordings, assignments, announcements, and project documentation. It incorporates organized menus, weekly content collapsibles, a pure HTML/CSS/JavaScript/Bootstrap interface, a much-improved engagement level, and streamlined communication.
